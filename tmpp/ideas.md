# 한국사회주택협회 원페이지 웹사이트 - 디자인 기획안

## 개요
사회주택의 가치와 혁신을 전달하면서도 실용적인 정보 접근성을 제공하는 원페이지 웹사이트를 위한 세 가지 디자인 철학을 제시합니다.

---

## 디자인 제안 1: 현대적 미니멀리즘 (Modern Minimalism)
**확률: 0.08**

### 디자인 철학
공공성과 투명성을 강조하는 현대적 미니멀리즘. 불필요한 장식을 제거하고 정보 계층과 공간을 극대화하여 신뢰감과 전문성을 전달합니다.

### 핵심 원칙
- **정보 우선**: 콘텐츠가 시각적 장식을 압도하지 않으면서도 명확하게 드러남
- **수직적 리듬**: 일관된 간격과 정렬로 읽기 흐름을 자연스럽게 유도
- **제한된 색상**: 2-3가지 주요 색상으로 시각적 집중력 강화
- **타이포그래피 주도**: 폰트 크기와 무게로만 계층 구조를 표현

### 색상 철학
- **기본색**: 깊은 남색(#1a365d) - 신뢰, 안정성
- **강조색**: 따뜻한 오렌지(#f97316) - 혁신, 에너지
- **배경**: 순백색(#ffffff) - 명확성, 개방성
- **텍스트**: 차콜그레이(#2d3748) - 가독성

### 레이아웃 패러다임
- 왼쪽 정렬 기반의 비대칭 레이아웃
- 섹션별로 텍스트와 이미지의 위치를 교대로 배치
- 여백을 통한 호흡감 강조
- 그리드 기반이 아닌 자유로운 흐름

### 시그니처 요소
- 얇은 수평선으로 섹션 구분
- 숫자와 통계를 강조하는 대형 타이포그래피
- 미니멀한 아이콘 시스템

### 상호작용 철학
- 부드러운 호버 효과 (배경색 미세 변화)
- 스크롤 시 요소들의 점진적 나타남
- 클릭 가능한 요소의 명확한 시각적 피드백

### 애니메이션
- 스크롤 트리거 페이드인 (opacity 0→1, 300ms)
- 버튼 호버 시 배경색 전환 (200ms ease-out)
- 숫자 카운팅 애니메이션 (1000ms)

### 타이포그래피 시스템
- **제목**: Noto Sans KR Bold (700) - 32px, 48px, 64px
- **본문**: Noto Sans KR Regular (400) - 16px, 18px
- **강조**: Noto Sans KR SemiBold (600) - 18px, 20px
- **라인하이트**: 1.6 (본문), 1.3 (제목)

## 디자인 제안 2: 따뜻한 휴머니즘 (Warm Humanism)
**확률: 0.07**

### 디자인 철학
사회주택의 본질인 '사람 중심'을 시각적으로 표현. 곡선, 부드러운 색상, 손그림 같은 요소들로 친근감과 따뜻함을 전달하면서도 전문성을 잃지 않습니다.

### 핵심 원칙
- **곡선 미학**: 모든 모서리를 둥글게 처리 (border-radius 16px 이상)
- **인간적 스케일**: 큰 여백과 숨 쉴 수 있는 공간
- **따뜻한 톤**: 자연에서 영감을 받은 색상 팔레트
- **스토리텔링**: 각 섹션이 연결된 이야기를 전달

### 색상 철학
- **기본색**: 따뜻한 테라코타(#c85a2f) - 안정감, 자연스러움
- **강조색**: 신선한 민트(#6ee7b7) - 희망, 성장
- **배경**: 크림색(#fffbf0) - 편안함, 포용성
- **텍스트**: 따뜻한 브라운(#5a4a42) - 부드러운 가독성

### 레이아웃 패러다임
- 중앙 정렬 기반이지만 요소들이 자유롭게 배치
- 섹션마다 다른 배경색으로 시각적 변화
- 카드형 요소들의 겹침과 오버플로우로 역동성 표현
- 곡선 분할선(SVG)으로 섹션 연결

### 시그니처 요소
- 손그림 스타일의 일러스트레이션
- 부드러운 그림자 (soft shadow)
- 원형 또는 둥근 사각형 배지

### 상호작용 철학
- 호버 시 요소가 살짝 떠오르는 효과
- 클릭 시 부드러운 스케일 변환
- 마우스 움직임에 반응하는 미묘한 패럴랙스

### 애니메이션
- 스크롤 시 요소들의 부드러운 슬라이드인 (200ms ease-out)
- 버튼 호버 시 배경색 전환 + 그림자 강화 (250ms)
- 카드 호버 시 transform: translateY(-8px) (200ms)

### 타이포그래피 시스템
- **제목**: Noto Sans KR Bold (700) + Noto Serif KR (serif 악센트) - 36px, 48px, 56px
- **본문**: Noto Sans KR Regular (400) - 16px, 17px
- **강조**: Noto Sans KR Medium (500) - 18px
- **라인하이트**: 1.7 (본문), 1.2 (제목)

## 디자인 제안 3: 대담한 모더니즘 (Bold Modernism)
**확률: 0.06**

### 디자인 철학
기하학적 형태와 대담한 색상 대비로 사회주택의 혁신성과 진보성을 강조. 현대적이고 역동적이면서도 정보 전달에 충실합니다.

### 핵심 원칙
- **기하학적 구성**: 삼각형, 사각형 등의 도형을 적극 활용
- **고대비 색상**: 어두운 배경과 밝은 강조색의 극적 대비
- **타이포그래피 실험**: 다양한 폰트 크기와 각도로 동적 표현
- **레이어링**: 겹쳐진 요소들로 깊이감 표현

### 색상 철학
- **기본색**: 진한 네이비(#0f172a) - 강인함, 현대성
- **강조색 1**: 생생한 라임(#84cc16) - 에너지, 진보
- **강조색 2**: 핫 핑크(#ec4899) - 혁신, 활력
- **배경**: 어두운 슬레이트(#1e293b) - 프리미엄감
- **텍스트**: 밝은 회색(#f1f5f9) - 고대비 가독성

### 레이아웃 패러다임
- 비대칭 그리드 기반 (3-column 불규칙 배치)
- 섹션마다 다른 각도의 배경 요소
- 텍스트와 이미지의 겹침으로 시각적 긴장감
- 대각선 분할선으로 동적 흐름

### 시그니처 요소
- 기하학적 배경 패턴 (삼각형, 라인)
- 대담한 그라데이션 오버레이
- 강조 텍스트의 배경 하이라이트

### 상호작용 철학
- 호버 시 색상 변환 (강조색으로 급격한 전환)
- 클릭 시 스케일 + 회전 효과
- 마우스 움직임에 따른 그라데이션 방향 변화

### 애니메이션
- 스크롤 시 요소들의 빠른 슬라이드인 (150ms ease-in-out)
- 버튼 호버 시 배경색 전환 + 회전 (150ms)
- 숫자 카운팅 애니메이션 (800ms)

### 타이포그래피 시스템
- **제목**: Space Grotesk Bold (700) - 40px, 56px, 72px
- **본문**: Noto Sans KR Regular (400) - 16px, 18px
- **강조**: Space Grotesk Medium (600) - 20px, 24px
- **라인하이트**: 1.5 (본문), 1.1 (제목)

## 선택 결정
**선택된 디자인: 따뜻한 휴머니즘 (Warm Humanism)**

### 선택 이유
- 사회주택의 본질인 '사람 중심'과 '공동체'를 가장 잘 표현
- 공공기관의 신뢰성과 친근감을 동시에 전달
- 다양한 이해관계자(입주자, 회원사, 정책입안자)에게 포용적으로 다가갈 수 있음
- 따뜻한 색상과 곡선으로 사회주택의 긍정적 이미지 강화
- 스토리텔링을 통해 각 섹션의 정보가 자연스럽게 연결됨

### 구현 방향
- 모든 섹션을 따뜻한 톤의 배경색으로 구분
- 곡선 SVG 분할선으로 섹션 연결
- 손그림 스타일의 일러스트레이션 활용
- 부드러운 호버 효과와 애니메이션
- Noto Sans KR + Noto Serif KR 조합으로 친근하면서도 전문적인 느낌
