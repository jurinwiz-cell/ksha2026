1. 이 폴더에 public1.png 이미지가 있으면 public1 채팅방의 로고가 됩니다.
2. 1번이 없으면 0.png 이미지가 채팅방의 로고가 됩니다.
3. 둘 다 없으면 채팅방 로고가 나오지 않습니다.

1. If there is a public1.png image in this folder, it becomes the logo of the public1 chat room.
2. If there is no 1, the 0.png image becomes the logo of the chat room.
3. Without both, the chat room logo will not appear.

-

1. 이 폴더에 public1/style.min.css 파일이 있으면 public1 채팅방에 적용됩니다.
2. 1번이 없고 0/style.min.css 파일이 있으면 모든 채팅방에 적용됩니다.
3. 둘 다 없으면 default/style.min.css 파일이 모든 채팅방에 적용됩니다.

1. If there is a public1/style.min.css file in this folder, it will be applied to the public1 chat room.
2. If there is no number 1 and there is a 0/style.min.css file, it is applied to all chat rooms.
3. If neither exists, the default/style.min.css file will be applied to all chat rooms.
