# ddggshop 스토어프론트 다국어(i18n)

이 폴더는 **쇼핑몰 화면(스토어프론트)** 의 언어 사전입니다.
(관리자 콘솔/백엔드 문구는 라이믹스 표준 방식인 `modules/ddggshop/lang/` 을 사용합니다.)

## 언어 추가 방법

1. `ko.php` 를 복사해 `langs/<언어코드>.php` 로 저장합니다. (예: 일본어 → `langs/ja.php`)
   - 언어코드는 소문자 알파벳/숫자만 사용하세요 (`ja`, `zh`, `zh-cn`, `es` 등).
2. 파일 안의 `'name'` 값을 해당 언어 표기로 바꿉니다. (예: `'日本語'`)
3. `'strings'` 의 **값만** 번역합니다. **키(왼쪽)는 절대 바꾸지 마세요.**
4. 관리자 → **쇼핑몰설정 › 기본 설정 › 다국어** 에서 추가한 언어를 노출 언어로 켜면
   스토어프론트 언어 선택기에 나타납니다.

## 동작 규칙

- `ko.php` 가 **기준 파일**입니다. 모든 키가 여기에 있어야 하며, 다른 언어 파일에서
  빠진 키는 자동으로 한국어(ko.php) 값으로 대체됩니다. (화면이 비지 않습니다)
- 방문자가 선택한 언어는 쿠키(`ddggshop_lang`)에 저장됩니다. 선택 전에는
  관리자가 지정한 **기본 언어**로 표시됩니다.
- 파일을 추가/수정한 뒤 화면에 반영되지 않으면 관리자에서 **캐시 비우기** 를 한 번 하세요.

## 파일 형식 예시

```php
<?php
if (!defined('__XE__')) exit();
return array(
    'name' => '日本語',
    'strings' => array(
        'cart'  => 'カート',
        'login' => 'ログイン',
        // ... ko.php 의 나머지 키를 번역
    ),
);
```
