## [1.18.0] - 2026-08-28

### Added (추가)
- **회원 그룹(등급)별 가격 할인**: 기타설정에 ‘등급(회원그룹)별 가격 할인’을 추가했습니다. 그룹마다 **할인율(%) 또는 할인금액(원)** 을 지정하며, 회원이 여러 그룹에 속하면 가장 큰 할인이 적용됩니다. 상품 상세·목록·장바구니·주문서에 할인가·원가(취소선)·회원 할인 배지가 표시되고, 장바구니·바로구매·옵션 합계까지 서버 재계산으로 실제 청구가에 반영됩니다. (기존 회원공개 가격 기능과 별개)
- **홈 블록 ‘상품 목록 순서(관리자 정렬순)’ 소스**: 홈 화면 블록에 상품목록의 드래그 정렬 순서(list_order)를 그대로 따르는 소스 타입을 추가했습니다. (기존 ‘신상품’=등록일순, ‘베스트셀러’=판매량순이라 관리자 정렬을 반영하지 못하던 요구 대응)
- **단일상품 총 상품금액 표시**: 옵션이 없는 상품도 상품 상세에서 수량 × 가격의 총 상품금액이 실시간 표시됩니다(구매자가 직접 계산 불필요).
- **해외/지역별 추가배송비**: 추가배송비 규칙에서 우편번호 시작/끝을 **선택사항**으로 바꿨습니다. 우편번호 없이 **지역명만**(해외 지명 등) 등록하면 주문서에 **‘배송 지역’ 선택 드롭다운**으로 노출되어, 선택 시 해당 추가배송비가 가산됩니다(서버 재검증). 한국 우편번호 구간 규칙은 기존대로 우편번호 자동 매칭됩니다.
- **카테고리명 다국어**: 카테고리 관리에서 활성 언어(기본 언어 제외)별 **번역명**을 입력할 수 있습니다. 스토어프론트의 헤더 메뉴·드로어·상품목록 내비/타이틀·브레드크럼과 상세 브레드크럼이 활성 언어 기준으로 표시되며, 번역이 없으면 기본명으로 대체됩니다. (스토어프론트 i18n 파일 방식과 일관되게 관리자 UI에서 직접 번역)

### Fixed (수정)
- **마이페이지 배송지 관리 직접입력 미적용**: 주소 입력방식을 ‘직접입력(해외 주소)’으로 설정해도 배송지 추가 폼이 항상 우편번호 검색만 노출하던 버그 수정. 이제 주문서와 동일하게 설정을 따릅니다.

### Database (스키마)
- `ddggshop_category`에 `name_i18n`(카테고리명 번역, JSON) 컬럼 추가 — 모듈 업데이트 시 자동 마이그레이션.

## [1.17.3] - 2026-07-21

### Added (추가)
- **구매 후 회원 그룹 변경 (콘텐츠 상품용)**: 상품 등록/수정에 ‘구매 후 회원 그룹 변경’을 추가했습니다. 켜면 결제가 완료될 때(무통장은 관리자 입금확인 시) 구매 회원의 그룹을 지정대로 **제거·추가(이동)** 하여, 유료 게시판 열람권한 등 콘텐츠 접근 권한을 자동 부여할 수 있습니다. ‘제거할 그룹’과 ‘추가(이동)할 그룹’을 각각 선택하며, 회원 주문만 대상이고(비회원 제외) 환불 시 자동 회수는 하지 않습니다(수동 관리).

## [1.17.2] - 2026-07-21

### Added (추가)
- **상품별 1인당 구매 수량 제한**: 상품 등록/수정에 ‘1인당 구매 제한’을 추가했습니다. **0은 무제한**, N을 지정하면 회원 1인당 최대 N개까지만 구매할 수 있습니다(한정판·1인 1개 이벤트 등). 회원은 취소·환불을 제외한 **누적 구매수량** 기준이며, 비회원은 1회 주문 내 수량으로 제한됩니다. 장바구니 담기와 주문 생성 두 단계에서 서버가 검증하며, 상품 상세에 ‘구매 제한: 1인당 N개’로 안내됩니다. (기존 상품은 모두 무제한)

## [1.17.1] - 2026-07-21

### Added (추가)
- **브라우저 언어 자동감지**: 다국어 사용 시, 방문자가 언어를 직접 고르기 전에는 브라우저 언어(Accept-Language)를 노출 언어와 매칭해 자동으로 표시합니다. 우선순위는 방문자 선택(쿠키) → 브라우저 언어 → 관리자 기본언어이며, 미지원 언어는 기본언어로 대체됩니다.

### Fixed (수정)
- **언어 선택기 클릭 시 오류**: 언어 전환 액션이 GET 링크로 호출되어 ‘사용할 수 없는 HTTP 메소드(405)’가 뜨던 문제와, 파라미터명이 Rhymix 예약어(`lang`)와 충돌해 ‘Lang 객체 변환 오류’가 나던 문제 수정. (액션 GET 허용 + 파라미터명 `setlang` 변경)
- **SVG 로고 업로드 불가**: 사이트 로고를 SVG로 업로드하면 허용 확장자 목록에 없어 저장되지 않던 문제 수정(svg 허용).
- **홈 화면 구성 블록 저장 후 이동 오류**: 블록 편집 저장 시 쇼핑몰 홈으로 이동하던 문제 수정. 이제 ‘홈 화면 구성’ 페이지로 돌아옵니다.

## [1.17.0] - 2026-07-21

### Added (추가)
- **스토어프론트 다국어(i18n) — 한국어/영어 기본 제공**: 쇼핑몰 화면 전체를 여러 언어로 표시할 수 있습니다.
  - `쇼핑몰설정 > 기본 설정 > 다국어`에서 사용 여부·기본 언어·노출 언어를 설정. 켜면 헤더(및 모바일 메뉴)에 언어 선택기가 표시되고, 방문자가 고른 언어는 쿠키에 저장됩니다.
  - 사용자가 언어 파일을 직접 추가할 수 있는 파일 기반 구조: `modules/ddggshop/langs/` 에 `<코드>.php`(예: `ja.php`)를 추가하면 자동 인식됩니다. `ko.php`가 기준이며, 빠진 키는 한국어로 자동 대체됩니다.
  - 적용 범위: 홈·상품목록·상세·장바구니·주문/결제·주문완료·주문조회·마이페이지·주문내역·배송지·쿠폰함·찜한 상품 등 **모든 스토어프론트 페이지**의 정적 문구, 서버 생성 라벨(주문상태·교환/반품·결제수단·주문단계·상태필터), 브라우저 탭 제목, 그리고 shop.js의 알림/확인 문구까지 포함.
  - 관리자 콘솔은 기존대로 한국어로 유지됩니다.

## [1.16.2] - 2026-07-06

### Added (추가)
- **주문상품 상품코드 표시**: 주문서 출력(관리자)의 주문 상품 표에 상품코드 열을 추가하고, 주문 상세 화면에도 상품명 아래 코드를 표기합니다. 주문 시점의 상품코드를 주문상품에 스냅샷으로 저장하며(상품명·썸네일과 동일 방식), 코드가 저장되지 않은 과거 주문은 현재 상품에서 조회해 보완합니다.
- **주소 입력 방식 선택(해외 사용자 대응)**: `쇼핑몰설정 > 주문 설정`에 ‘주소 입력 방식’을 추가했습니다. 기본은 **우편번호 검색**(국내 주소 검색 팝업)이며, **직접 입력**을 선택하면 우편번호·주소를 자유롭게 타이핑할 수 있어 해외 주소 입력에 적합합니다.

## [1.16.0] - 2026-07-05

### Added (추가)
- **주문 설정 탭 · 배송 주소 선택 수집**: 기프트콘·콘텐츠처럼 배송이 필요 없는 상품은 주문서에 배송지 입력창 없이 주문할 수 있습니다. `쇼핑몰설정 > 주문 설정` 탭에서 주소 수집 정책(상품 설정에 따름 / 항상 받기 / 받지 않기)을 정하고, 상품 등록·수정 화면에서 상품별로 `배송 주소 입력 받지 않기`를 지정할 수 있습니다. 배송상품과 기프트콘을 한 쇼핑몰에서 함께 판매할 수 있으며, 주소를 받지 않는 주문은 배송비도 부과되지 않습니다. 배송 요청사항 입력란 표시 여부도 설정 가능합니다.
  - `ddggshop_item.require_address` 컬럼 추가(스키마 + 마이그레이션, 기존 상품 기본값 `Y`). 주소 필요 여부는 서버에서 재판정하여 클라이언트 우회를 방지합니다.
- **쿠폰 개별 회원 발급**: 전체·그룹 단위 발급에 더해 특정 회원에게 직접 발급하는 기능 추가(보상 지급 등). 아이디·닉네임·이메일로 회원을 검색해 선택한 뒤 한 번에 발급하는 팝업을 제공하며, 이미 보유한 회원은 자동 제외됩니다.
- **최근 본 상품 노출 개수 설정**: ‘최근 본 상품’ 위젯에 보여줄 상품 수를 레이아웃 설정에서 1~30개로 지정할 수 있습니다(기본 5개). 기존에는 개수 제한이 없었습니다.

## [1.15.2] - 2026-06-25

### Added (추가)
- **상품 주소 RESTful 개편**: 상품 상세·카테고리 주소가 `/product/101786`, `/category/12`처럼 짧고 깔끔하게 바뀌었습니다(getUrl 양방향 라우팅). 공유·검색엔진 노출에 유리합니다.
- **상품 공유 버튼**: 상품 상세 ‘찜하기’ 옆에 공유 버튼 추가. PC는 링크 복사 후 우측 상단 토스트로 안내, 모바일은 기기 공유 시트를 호출합니다.
- **최근 본 상품 위젯**: 모든 페이지 우측에 최근 본 상품 썸네일을 보여주는 플로팅 리모콘. 접기/펼치기·맨 위로 지원, 레이아웃 설정에서 표시 ON/OFF.
- **가격대 필터 직접 입력**: 상품목록 좌측 필터에 최소~최대 가격을 직접 입력하는 범위 검색 추가.
- **가격대(밴드) 관리자 커스텀**: 가격 필터의 가격대 구간을 관리자에서 직접 설정. 고가 상품 쇼핑몰에 맞춘 구간 구성 가능.
- **카테고리 상품 개수 표시**: 카테고리별 상품 수 노출 여부를 관리자에서 ON/OFF.
- **예상 이익 통계**: 관리자 통계에 매출뿐 아니라 예상 이익(매출−원가)을 함께 표시.
- **쿠폰 수정 기능**: 발급한 쿠폰을 나중에도 수정 가능(사용횟수·상태는 유지).
- **품절 알림**: 특정 옵션 조합 또는 단일 상품의 재고가 0이 되면 관리자에게 알림 발송(알림센터 연동, 기타 설정에서 ON/OFF).

### Changed (변경)
- **콘솔 라이믹스 관리자 바로가기**: 쇼핑몰 콘솔 헤더에 라이믹스 관리자로 이동하는 텍스트 버튼 추가(사이트 관리자에게만 노출).

### Fixed (수정)
- **옵션 상품 재고 동기화**: 주문 시 본체(판매정보) 재고가 차감되지 않던 문제 수정. 옵션 사용 상품은 본체 재고를 옵션 조합 재고의 합계로 자동 산정하며, 상품 폼에서 직접 입력하지 않습니다.
- **pretty URL 상대경로 링크 404**: RESTful 주소(`/product/…`)에서 상대경로(`./`)로 만들어지던 일부 스토어프론트 링크(장바구니 이동 등)가 404로 가던 문제를 전수 점검·절대경로화하여 수정.
- **상품문의 알림 클릭 시 ERR_ACT_IS_NOT_STANDALONE 오류**: 상품문의 등록/답변 알림의 이동 URL에 쇼핑몰 mid가 빠져, 알림 클릭(리다이렉트) 시 standalone이 아닌 액션으로 라우팅되며 오류가 발생하던 문제 수정. 알림 URL을 `ddggshopModel::productUrl()`(쇼핑몰 mid 명시)로 생성하도록 변경. 주문 알림과 동일한 방식.

### Security (보안)
- **비밀글 문의의 답변까지 비인가 열람자에게 노출되지 않도록 강화**: 기존에도 기본·skinGuide 스킨은 비밀글 질문/답변을 가렸으나, 커스텀 스킨에서 가드를 누락할 경우를 대비해 **뷰(서버) 단계에서 비인가 열람자에게는 비밀글의 질문·답변 내용을 아예 비워** 전달하도록 변경(작성자 본인·관리자만 열람). 스킨과 무관하게 비밀글이 강제 보호됩니다.

- **주문번호 UNIQUE 제약**: `ddggshop_order.order_code`에 UNIQUE 인덱스 추가(기존 설치는 모듈 업데이트 시 마이그레이션). 동시 주문 시 주문번호 충돌이 나면 코드 재생성 후 재시도하고, DB 제약이 최종 안전망 역할을 한다.

### Fixed (수정) — 안정성·정합성
- 토스 결제 알림이 결제 성공 전(주문 생성 시점)에 발송되던 문제 → 토스는 결제 승인 후, 무통장은 주문(입금대기) 시 발송하도록 수정.
- **관리자 주문취소/환불 정합성**: 관리자가 주문을 ‘취소/환불’로 바꿀 때 상태만 변경되고 재고·적립금·쿠폰·PG 환불이 처리되지 않던 문제 → 고객 취소와 동일한 중앙 처리 파이프라인(`ddggshopModel::cancelOrder`)으로 통합. 재고 복원 + 적립 포인트 회수 + 사용 적립금 환불 + 쿠폰 사용 복원 + 토스 PG 취소(환불)를 한 트랜잭션에서 일괄 처리.
- **쿠폰 복원**: 주문 취소 시 사용한 쿠폰이 복원되지 않던 문제 → `coupon.used_count` 감소, 사용 로그(`coupon_log`) 삭제, 회원 보유 쿠폰(`coupon_issue`) 미사용 복원.
- **재고 동시성(오버셀링)**: 재고 차감/복원이 PHP read-modify-write라 동시 주문 시 재고가 어긋나던 문제 → SQL 원자 연산(`stock = stock ± qty`)으로 변경. 주문 생성 단계는 `stock >= qty` 가드 조건부 차감으로 재고 부족 시 거부(친화적 품절 메시지), 토스 승인 단계는 이미 결제 완료이므로 무조건 차감.
- **중복 결제 멱등성**: 토스 결제 콜백/입금확인이 동시 또는 중복 진입해도 `ready/pending → paid` 가드 업데이트 + 적용 행수 확인으로 재고 이중 차감·포인트 이중 적립을 방지.
- **적립금 차감 트랜잭션 일관성**: 토스 승인 시 적립금 ‘사용 차감’이 트랜잭션 밖에서 실행돼 부분 실패로 정합성이 깨질 수 있던 문제 → 트랜잭션 내부로 이동.
- **쿠폰 사용 표시 누락**: 회원이 쿠폰 사용 시 발급분(`coupon_issue`)의 `used` 플래그가 잘못된 속성(`value=`)으로 설정되지 않아 쿠폰함에서 사라지지 않던 문제 → `default=` 로 수정.
