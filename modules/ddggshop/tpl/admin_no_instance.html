쇼핑몰을 시작하려면 메뉴를 먼저 만들어 주세요

쇼핑몰 모듈은 설치되었지만, 아직 사이트에 연결된 쇼핑몰 페이지(인스턴스)가 없습니다.
메뉴 관리에서 ‘쇼핑몰’ 유형의 메뉴를 하나 추가하면 스토어프론트와 관리 콘솔이 활성화됩니다.

  1. 아래 메뉴 관리 버튼을 클릭합니다.
  2. 메뉴 추가 → 모듈에서 쇼핑몰을 선택하고, 주소(mid)를 정한 뒤 저장합니다.
  3. 저장 후 다시 쇼핑몰 모듈로 들어오면 새 관리 콘솔로 자동 이동합니다.
메뉴 관리로 이동 →

메뉴를 만들기 전까지는 상품·주문 관리를 사용할 수 없습니다.
